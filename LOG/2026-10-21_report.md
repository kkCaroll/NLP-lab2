# 统计定稿与报告生成记录

## 目的

在主实验、随机顺序复跑、无测试消融与回归敏感性诊断完成后，统一重新生成统计表、图、报告与演示文稿，确保正文数字可由 CSV 追溯。

## 命令

```bash
python harness/audit_run.py --run-id 2026-10-21_ablation --check-initial-logs
python harness/aggregate.py --run-id 2026-10-21_ablation \
  --output RECORD/analysis/ablation
python harness/count_tool_attempts.py --run-id 2026-10-21_ablation
python harness/analyze.py \
  --reliability RECORD/analysis/reliability/episode_level.csv \
  --ablation RECORD/analysis/ablation/episode_level.csv
python harness/make_figures.py
```

## 修改

1. `harness/run_batch.py` 在无测试模式下先解析有效配置，再写入批清单的 `config` 与 `config_sha256`。此前批清单记录主配置路径，实际逐题配置为消融配置。
2. 依据十六份 `run_config.json` 更正 `RECORD/runs/2026-10-21_ablation/batch_manifest.json` 的配置字段与哈希。该修正不改变 episode、评分或统计结果。
3. `harness/analyze.py` 的消融表增加说明，指出该表仅使用两次运行均进入分支的 episode，MiMo 交集为两题，不代表八题全样本。表头改为“主减消融”以明确差值方向。
4. 重新生成 `RECORD/analysis/main_results.md`、`main_results.csv` 与 `statistics.json`。
