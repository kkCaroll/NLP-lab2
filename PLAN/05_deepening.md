## 1. 目标

v0 已说明负面反馈与较低修复成功率相关，失败以未编辑和预算耗尽为主。当前主要缺口有四项。

1. 主实验条件顺序固定，条件与任务内位置共线，主结果不能作因果解释。
2. 每个条件在每个任务上只运行一次，无法区分条件效应与运行间波动。
3. 质性编码未完成，机制解释只依赖三个案例。
4. 统计功效低，不显著结果不能区分小效应与无效应。

深入研究的目标不是增加题数，而是补上内部效度与机制证据，使结论强度与数据强度匹配。

## 2. 新增研究问题

| 编号 | 问题 | 主要证据 |
|---|---|---|
| RQ2 | 随机化条件顺序并重复运行后，负面反馈是否仍降低修复成功率 | 三次重复的随机顺序实验 |
| RQ3 | 负面反馈通过什么过程导致失败 | 事件流过程指标与质性编码 |
| RQ4 | 方法指引的作用是否独立于负面语气 | 五条件对照与重复运行 |
| RQ5 | 条件效应在任务与重复之间的稳定性如何 | 混合效应模型或分层汇总 |

## 3. 三条路线

| 路线 | 内容 | 模型调用 | 预计时间 | 适用情况 |
|---|---|---|---|---|
| A 最小可行 | 质性编码、过程指标、功效分析、报告 v1 | 无 | 2 至 3 天 | 时间紧张，优先补机制 |
| B 推荐 | A 加六题两次重复复跑 | 约 70 至 90 个分支 episode | 3 至 4 天 | 需要较强因果与稳定性证据 |
| C 扩展 | B 加至八题或增加重复次数 | 约 150 个以上分支 episode | 4 天以上 | 时间充足，追求更稳估计 |

默认建议先完成 A，再根据剩余时间决定是否进入 B。B 的运行可以放在后台，编码与分析同步进行。

## 4. 阶段安排

### P7.1 准备与冻结

1. 保持 24 题与主实验数据不变，新增目录 `RECORD/analysis/deepening/`。
2. 从 `main_manifest.json` 与 `tasks_manifest.json` 复核哈希，确认研究期间任务集未变化。
3. 预注册本轮分析的主结果、次结果与排除规则，写入 `PLAN/05_deepening.md` 的附录或独立文件。
4. 质性编码前先写编码手册，为八个维度各给两条正例与两条反例。

验收标准为数据哈希一致，编码手册完成，分析口径在编码前固定。

### P7.2 质性编码

1. 对三十一条样本建立盲化副本，隐藏条件名与模型名，随机编号。
2. 按八个维度编码，每个判断必须能回溯到事件流的工具调用序号或 diff 行。
3. 完成后间隔至少二十四小时，随机抽取十条重编码，计算同一编码者的一致率与 Cohen kappa。
4. 若有同学愿意参与，另抽十条做双人编码，报告编码者间一致率。没有第二人时明确说明。
5. 输出 `coding_sheet.csv`、`coding_memo.md` 与 `casebook.md`，案例集保留四至六个可追溯案例。

验收标准为三十一条全部有编码，无空值，重编码一致率可计算，案例可回溯。

### P7.3 过程指标

1. 新增 `harness/process_metrics.py`，只读取现有事件流，不调用模型。
2. 提取以下指标。
   - 首次编辑前的工具调用次数。
   - 首次编辑前是否读取错误日志或测试输出。
   - 搜索调用、读取调用与编辑调用的次数。
   - 重复读取同一文件的次数。
   - 读取文件数与编辑文件数。
   - Bash 尝试次数与权限拒绝次数。
   - 是否发生编辑、是否预算耗尽、是否在最后一次读取后仍未编辑。
3. 按模型、条件与任务聚合，输出 `process_metrics.csv` 与条件对比图。
4. 对五个 episode 逐条对照原始事件流，确认计数正确。

验收标准为指标可由脚本重建，抽查一致，报告只把过程指标作为机制证据，不作因果中介结论。

### P7.4 随机顺序重复实验

1. 任务沿用可靠性复跑的六题，T05、T09、T14、T18、T19、T24。
2. 新增两次独立复跑，运行编号为 `2026-10-22_replication_r2` 与 `2026-10-22_replication_r3`。
3. 每次复跑包含两模型五条件，条件顺序在任务内随机化，种子由运行编号、模型与任务名派生并写入记录。
4. 第一轮与第二轮预算、编辑上限、超时与主实验一致。
5. 保留停止规则，出现超时、非预算原因的非零退出或分支继承不一致时停止并检查。
6. 与已有 `2026-10-21_reliability` 合并为三次重复，分析任务内与重复间的方差。
7. 主分析使用混合效应 logistic 回归，任务与重复作为随机截距，条件作为固定效应。模型不收敛时退化为逐任务比例与 Friedman 检验。

验收标准为三次复跑审计通过，条件顺序有记录，主分析同时报告效应量与置信区间。若时间不足，只做 A 路线，不启动本阶段。

### P7.5 统计深化

1. 对主实验的十四对与六对失败样本做精确 McNemar 功效分析，报告当前设计可检测的最小效应。
2. 对重复实验报告条件间风险差、比值比与 bootstrap 置信区间。
3. 做四项敏感性分析。
   - 排除测试篡改 episode。
   - 排除预算耗尽 episode。
   - 标准题与困难题分层。
   - 全样本口径与分支子集口径并列。
4. 多重比较继续使用 Holm 校正，但结论以效应量与区间为主，不以 p 值二分。

验收标准为每个主要结论都有点估计与区间，不显著结果写明证据不足而非无效应。

### P7.6 报告与演示 v1

1. 保留 v0，新增 `report_v1.md` 与 `slides_v1.md`，不覆盖已提交版本。
2. 报告新增机制一节，整合质性编码与过程指标。
3. 重写效度威胁一节，区分已修复的顺序问题、仍存在的样本量与任务构造问题。
4. 结论按证据强度分级，明确哪些是描述性关联，哪些是重复实验支持的条件差异。
5. 演示文稿在报告定稿并经用户复核后生成，不提前渲染。

验收标准为报告数字可由 CSV 追溯，结论不超出设计支持范围，v0 与 v1 的差异有说明。
