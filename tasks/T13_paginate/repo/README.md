# pagekit

Small utilities for paging and window slicing.

## Modules

- `pagekit.limits`: numeric checks and interval limits shared by callers.
- `pagekit.paginate`: page counts, page resolution and item paging.
- `pagekit.slicing`: fixed size windows over a list.
- `pagekit.chunks`: page ranges and per-page chunks.
- `pagekit.report`: progress bars and paged text.
