# logistics

Small parcel weight and shipping fee utilities.

## Modules

- `logistics.units`: convert grams, kilograms and pounds.
- `logistics.parcels`: parse and describe parcels.
- `logistics.rates`: base rates, zone surcharges and express multipliers.
- `logistics.fees`: shipping fees, quotes and fee tables.
- `logistics.batches`: batch totals, grouping and summaries.
