# slugkit

Small utilities for slugs, titles and text segments.

## Modules

- `slugkit.whitespace`: whitespace and blank line normalisation.
- `slugkit.accents`: accent folding used before slug generation.
- `slugkit.slug`: slug generation and uniqueness.
- `slugkit.title`: title capitalisation and shortening.
- `slugkit.segments`: word splitting and word level helpers.
- `slugkit.report`: slug indexes, paths and headings.
