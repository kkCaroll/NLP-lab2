# mergekit

Small utilities for merging versioned records.

## Modules

- `mergekit.fields`: default fields and record completion.
- `mergekit.records`: grouping, merging and version selection.
- `mergekit.order`: ordering and identifier helpers.
- `mergekit.conflicts`: conflict detection between versions.
- `mergekit.report`: record and summary text.
