# confkit

Small utilities for configuration loading and boolean parsing.

## Modules

- `confkit.booleans`: text to boolean conversion.
- `confkit.config`: defaults, merging and overrides.
- `confkit.cli`: command line option parsing.
- `confkit.validate`: key and type checks.
- `confkit.env`: environment style configuration values.
- `confkit.report`: configuration text.
