# moneykit

Small utilities for exact monetary amounts.

## Modules

- `moneykit.amounts`: conversion to decimal amounts.
- `moneykit.rounding`: cent and unit rounding.
- `moneykit.totals`: sums, averages and rates.
- `moneykit.percent`: percentage shares and taxes.
- `moneykit.currency`: currency labels and amount arithmetic.
- `moneykit.format`: amount text.
