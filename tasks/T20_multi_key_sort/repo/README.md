# recordkit

Small employee record ordering and reporting utilities.

## Modules

- `recordkit.records`: validate and normalize record fields.
- `recordkit.keys`: shared multi-key ordering rules.
- `recordkit.sorting`: sorting, selection and ranking.
- `recordkit.grouping`: department grouping and summaries.
- `recordkit.report`: dictionary and text reports.
