# seqkit

Small utilities for duplicate detection, counts and positional reports.

## Modules

- `seqkit.validate`: sequence and hashability checks.
- `seqkit.search`: first duplicate, duplicate positions and presence checks.
- `seqkit.stats`: duplicate counts, ranking and ratio.
- `seqkit.analysis`: repeat gaps and repeated runs.
- `seqkit.report`: combined duplicate report.
