# payloadkit

Small utilities for JSON payloads and envelopes.

## Modules

- `payloadkit.serialise`: JSON text and byte conversion.
- `payloadkit.envelope`: envelope construction and parsing.
- `payloadkit.unicode`: text, non-ASCII and payload helpers.
- `payloadkit.normalise`: payload normalisation and flattening.
- `payloadkit.report`: payload descriptions.
