# clikit

Small command line helpers with boolean flags.

## Modules

- `clikit.flags`: text to boolean conversion.
- `clikit.options`: parser construction and parsed values.
- `clikit.args`: low level argument list helpers.
- `clikit.validate`: command and option checks.
- `clikit.commands`: greeting and summary commands.
- `clikit.report`: option and result text.
