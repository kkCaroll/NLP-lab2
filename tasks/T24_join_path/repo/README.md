# pathmont

Small utilities for forward slash path text.

## Modules

- `pathmont.normalize`: separator and segment normalisation.
- `pathmont.join`: path, URL and name joining.
- `pathmont.roots`: root containment and relative paths.
- `pathmont.extensions`: file extension helpers.
- `pathmont.segments`: untrusted segment checks.
- `pathmont.report`: path text.
